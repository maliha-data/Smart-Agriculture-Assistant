# 🌱 Smart Agriculture Assistant

## 📌 Project Overview
Smart Agriculture Assistant is a Python-based application designed to support smarter agricultural practices through an interactive and user-friendly interface.

The project uses Streamlit to provide an easy-to-use web interface and integrates data-handling tools to support agricultural information and services.

## 🚀 Technologies Used
- Python
- Streamlit
- Pandas
- Requests
- JSON

## ✨ Features
- Interactive user interface
- Agricultural assistance
- Data handling using Pandas
- API integration using Requests
- User-friendly application design

## 📂 Project Structure
```text
Smart-Agriculture-Assistant/
│
├── agricultureproject.py

```

## ⚙️ Installation and Setup

1. Clone the repository:
```bash
git clone https://github.com/maliha-data/Smart-Agriculture-Assistant.git
```

2. Navigate to the project folder:
```bash
cd Smart-Agriculture-Assistant
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Run the application:
```bash
streamlit run agricultureproject.py
```
